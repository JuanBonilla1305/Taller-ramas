Taller de árboles de commits

Bitácora de Ramas

Pega el registro de tu repositorio y compara, al instante, tu árbol de commits contra el objetivo del taller. Todo se procesa en tu navegador — nada se envía a ningún servidor.

Corre este comando en la raíz de tu repositorio (con tus ramas y tags ya creados) y copia toda la salida:

git log --all --topo-order --pretty=format:"%H@@F@@%P@@F@@%D@@F@@%B@@R@@"

Mejor aún: no selecciones el texto a mano en la terminal — con historiales largos es facilísimo que se corte a media línea sin que lo notes. Manda la salida directo al portapapeles con uno de estos:

git log --all --topo-order --pretty=format:"%H@@F@@%P@@F@@%D@@F@@%B@@R@@" | Set-Clipboard
git log --all --topo-order --pretty=format:"%H@@F@@%P@@F@@%D@@F@@%B@@R@@" | pbcopy
git log --all --topo-order --pretty=format:"%H@@F@@%P@@F@@%D@@F@@%B@@R@@" | xclip -selection clipboard

Después solo pega (Ctrl+V) directo en el cuadro de abajo. Nota: aquí solo se confirma que el tag existe; el contenido de su mensaje (`git tag -a`) solo se valida en GitHub.
